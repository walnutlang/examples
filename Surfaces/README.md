# Surfaces

Curated host demos for Walnut: **`collection` / `item`** (`UICollectionView`) and **`map`** (`MKMapView` with marker items).

```sh
./.build/release/walnut check Examples/Surfaces
walnut simulator  # from Surfaces/
```

See [docs/views.md](https://docs.walnutlang.com/) and [docs/whats-new.md](https://docs.walnutlang.com/).
