# Ledger

Small-business cashbook demo for Walnut’s curated **`table` / `section` / `cell`** → `UITableView` bridge, with a system **`tabBar`** root and a **`navStack`** on Books for entry detail.

```sh
walnut simulator  # from Ledger/
```

## Screens

- **Books** — inset-grouped table of entries, sectioned by month
- **Entry** — add / view a line (payee, category, amount, note)
- **Summary** — income / expense / balance cards

Fake seed data models a neighborhood café: rent, supplies, card payouts, tips.
